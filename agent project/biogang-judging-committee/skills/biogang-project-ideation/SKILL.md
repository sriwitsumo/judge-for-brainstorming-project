# คิดโครงงานประกวด — Biogang Challenge 2026 Ideation Skill (Cowork multi-agent edition)

## บริบท

ทีมนักเรียน ม.ปลาย กำลังหาไอเดียโครงงานสำหรับ **Biogang Challenge 2026** เป้าหมายคือไอเดียที่ **นวัตกรรมจริง** และต้องผ่านการตรวจสอบที่เข้มเหมือนกรรมการระดับชาติ/นานาชาติจริงก่อนถึงจะถูกนำเสนอ

รายละเอียดกติกา/กำหนดการ/เกณฑ์คะแนนเต็มอยู่ที่ `references/competition-brief.md` — เปิดอ่านเมื่อต้องยืนยันวันที่/เงินรางวัล/กติกาการสมัคร ฐานความรู้เรื่องรูบริกกรรมการจริง (ISEF, YSC, I-New Gen ฯลฯ) อยู่ที่ `references/judging-knowledge-base.md`

**กฎเหล็กที่สำคัญที่สุด: ห้ามโชว์ไอเดียที่ยังไม่ผ่านกรรมการทั้ง 5 ท่านให้ผู้ใช้เห็นเด็ดขาด** งานคิด+วิจารณ์+แก้เกิดขึ้นเบื้องหลังทั้งหมด สิ่งที่ผู้ใช้เห็นคือไอเดียที่ "ผ่านแล้ว" เท่านั้น

## ความต่างจากเวอร์ชันเดิม (single-context role-play)

เวอร์ชันนี้ **ไม่สวมบทกรรมการเองอีกต่อไป** — กรรมการทั้ง 5 ท่านคือ agent จริงในปลั๊กอินนี้ (`agents/biogang-judge-*.md`) รันแยก context จริง ทำให้ "คิดอิสระก่อนค่อยอ่านความเห็นคนอื่น" เป็นจริง ไม่ใช่แค่จำลอง ส่วน STEP 1 (ทีม 3 คน) ก็แยกเป็น agent จริงเช่นกัน (`biogang-tech-brainstormer`, `biogang-bio-brainstormer`) เพื่อความสม่ำเสมอ — คุณ (ในฐานะ team lead ของบทสนทนานี้) ยังคงเป็นผู้สังเคราะห์และคุมภาพรวมทั้งหมด

## Quick-glance: ข้อจำกัดที่ต้องคิดถึงทุกไอเดีย

- **งบต้นแบบ:** < 10,000 บาท ต่อโครงการ (โซนปลอดภัยจริง ๆ คือ 3,000–7,000 บาท — เกิน 8,000 บาทเริ่มเสี่ยงโดนกรรมการท่านที่ 5 ทักเรื่องความสมจริง)
- **ผลกระทบ:** อย่างน้อยหลักหมื่นคนขึ้นไป ขยายผลระดับจังหวัด/ประเทศ/โลกได้
- **ต้องเลือก 1 ใน 3 หัวข้อ Nature Positive จริง:** (1) หยุดการสูญเสียธรรมชาติ (2) ฟื้นฟูพื้นที่เสื่อมโทรม (3) ใช้ทรัพยากรโดยไม่ทำลายสมดุล
- **ต้องพึ่งตนเองได้ (standalone):** ห้ามเป็นระบบที่ต้องพึ่งโครงสร้างพื้นฐานระดับเมือง
- **Novelty gate:** ถ้า "ถ่ายรูปธรรมดา + แชทบอทที่มองเห็นภาพ หรือแอปฟรีที่มีอยู่แล้ว" ทำสิ่งเดียวกันได้ = ตกทันที
- **ห้ามซ้ำหัวข้อโหล:** ถังขยะอัจฉริยะ, เครื่องรดน้ำอัตโนมัติ, เซนเซอร์ PM2.5 เดี่ยว ๆ, ระบบตรวจไฟป่าทั่วไป, แอปปลูกต้นไม้, IoT ธรรมดา

## กระบวนการ (3 ขั้นตอน วนลูป ทีละหัวข้อ)

ทำ**ทีละหัวข้อเท่านั้น** — เสนอ 1 ไอเดียที่ผ่านครบแล้ว รอ user ตอบรับ ค่อยไปหัวข้อถัดไป

### STEP 1 — ทีมระดมสมอง (agent จริง)

1. ตั้งโจทย์จาก pain point จริงในหัวข้อ Nature Positive ที่เลือก — ค้น web เช็ค prior art/งานวิจัยรองรับกลไกที่จะเสนอด้วยตัวเองก่อน (หน้าที่ team lead)
2. Dispatch โจทย์เดียวกันไปให้ `biogang-tech-brainstormer` และ `biogang-bio-brainstormer` **พร้อมกัน** (แต่ละตัวไม่เห็นกัน)
3. สังเคราะห์ผลลัพธ์ทั้งสองมุมเป็นไอเดียร่าง 1 ชิ้น ก่อนส่งกรรมการ

### STEP 2 — คณะกรรมการอิสระ 5 ท่าน (ส่วนสำคัญที่สุด)

1. ส่งไอเดียร่างชุดเดียวกัน (โจทย์เดียวกันทุกตัวอักษร) ไปให้ agent ทั้ง 5 ตัวนี้ **พร้อมกันในคำเรียกเดียว**:
   `biogang-judge-tech-engineering`, `biogang-judge-bio-environment`, `biogang-judge-research-methodology`, `biogang-judge-innovation-business`, `biogang-judge-feasibility-competition`
2. รอผลครบทั้ง 5 ก่อนอ่าน — ห้ามเผยผลของ agent ที่ได้มาก่อนให้ agent ที่ยังไม่ตอบเห็น
3. **Cross-Examination:** รวมคำถามซักถามของกรรมการทั้ง 5 (2–4 ข้อ/ท่าน) → เอาไปถามทีม (`biogang-tech-brainstormer`/`biogang-bio-brainstormer` หรือตอบเองถ้าเป็นเรื่องสังเคราะห์ภาพรวม) → ส่งคำตอบกลับไปหา **agent กรรมการตัวเดิม** (ใช้กลไก continue agent เดิม ไม่ใช่ agent ใหม่) เพื่อยืนยัน/ปรับ verdict คำตอบขอไปที (hand-wavy) = จุดอ่อนที่ยังไม่แก้ block การผ่านได้แม้คะแนนตัวเลขจะสูง
4. **Committee Discussion:** สรุปจุดที่เห็นตรงกัน, จุดที่เห็นต่าง, ข้อกังวลสำคัญที่สุด, สิ่งที่ควรแก้ก่อนอื่น — แก้ความเห็นต่างด้วยหลักฐาน ไม่ใช่ความเห็นส่วนตัว (หน้าที่ team lead ทำเอง)

#### Final Score (13 หมวด เต็มหมวดละ 10 = รวม /130)

Scientific Validity · Technical Feasibility · Engineering Quality · Research Methodology · Innovation · User Value · Cost Effectiveness · Equipment Availability · Budget Realism · Time Feasibility · Environmental Impact · Scalability · Presentation

รวมคะแนนจากที่แต่ละ agent กรรมการให้มาในโดเมนของตัวเอง (ดู "คะแนนที่รับผิดชอบหลัก" ในแต่ละไฟล์ agent) — หมวด **Presentation** ไม่มี agent ใดรับผิดชอบโดยตรง ให้ team lead ประเมินเองจากคุณภาพการนำเสนอไอเดียในภาพรวม หมวด **Scientific Validity** รับอินพุตทั้งจากกรรมการท่านที่ 2 (ฝั่งชีวะ) และท่านที่ 3 (ฝั่งระเบียบวิธี) ให้ team lead สังเคราะห์รวม

#### Final Verdict (เลือก 1)

🏆 Gold Award Candidate · 🥈 Silver Award Candidate · 🥉 Bronze Award Candidate · ⚠ Needs Major Revision · ❌ Not Feasible

**แนวทางคะแนน (ใช้วิจารณญาณประกอบ ไม่ใช่กฎตายตัว):** ≥115 → Gold, 95–114 → Silver, 80–94 → Bronze, 60–79 → Needs Major Revision, <60 → Not Feasible — **เกณฑ์ผ่านขั้นต่ำที่จะนำเสนอให้ user คือ Bronze ขึ้นไป (≥80/130) และต้องไม่มีจุดอ่อน "unresolved" จาก cross-examination ค้างแม้แต่ข้อเดียว และกรรมการท่านที่ 5 ต้องไม่ระบุ "ไม่ผ่านเกณฑ์แข็ง"**

### STEP 3 — วนลูป

เอาคำวิจารณ์กลับไปคุยกับทีม (`biogang-tech-brainstormer`/`biogang-bio-brainstormer`) อีกครั้ง: แก้ได้ไหม?
- **แก้ได้** → แก้แล้ว **วนกลับไป STEP 2** เสนอกรรมการชุดใหม่ (agent ใหม่ทั้ง 5 ตัว เพราะไอเดียเปลี่ยนไปแล้ว ต้องประเมินอิสระใหม่)
- **แก้ไม่ได้ / fatal flaw** → ทิ้งเงียบ ๆ เริ่มไอเดียใหม่สำหรับหัวข้อนั้น (**ห้ามบอก user ว่าไอเดียที่ทิ้งไปคืออะไร** เว้นแต่ user ถาม)

ทำวนซ้ำจนกว่าจะผ่านครบทั้ง 5 agent ที่ระดับ Bronze ขึ้นไปแบบไม่มีจุดอ่อนค้าง

## Tech-ratio ตามลำดับหัวข้อ

| หัวข้อที่ | สัดส่วนเทค | สัดส่วนชีวะ |
|---|---|---|
| 1–10 | 90% | 10% |
| 11–15 | 80% | 20% |
| 16–20 | เลือกเอง ตามความเหมาะสมของไอเดีย | |

## Template การนำเสนอแต่ละไอเดีย

ทุกไอเดียที่ผ่านกรรมการ ต้องมีครบ 11 หัวข้อนี้เสมอ:

1. ชื่อโครงงาน
2. ปัญหาที่แก้ไข
3. นวัตกรรมที่คิดค้น
4. หลักการทำงาน
5. เทคโนโลยีที่ใช้ (แยกงานเทค vs งานชีวะตามสัดส่วนของหัวข้อนั้น)
6. ความใหม่เมื่อเทียบกับงานเดิม (prior art ที่เจอจาก web search จริง)
7. ผลกระทบเชิงสิ่งแวดล้อม
8. ผลกระทบเชิงสังคม
9. ความเป็นไปได้ในการสร้างต้นแบบ (งบ + เหตุผล — ต้อง < 10,000 บาท)
10. โอกาสเชิงพาณิชย์
11. คะแนนความน่าสนใจ (เต็ม 10) + คะแนนกรรมการ /130 + verdict

## รูปแบบผลลัพธ์ที่ส่งให้ user

- นำเสนอ**ทีละหัวข้อ** รอ reaction ก่อนไปข้อถัดไป
- **สรุปย่อ** ว่าผ่านแล้ว พร้อมคะแนน /130 และ verdict — ไม่ต้อง dump บทสนทนาเต็มของ agent ทีม+กรรมการ เว้นแต่ user ขอดู deliberation เต็ม (ถ้าขอ สามารถโชว์ transcript อิสระของแต่ละ agent ได้จริง เพราะรันแยก context จริง)
- ถ้า user บอกว่าไอเดีย "ไม่ผ่าน" (แม้จะผ่านกรรมการภายในแล้ว) ให้รับฟังเป็นคำวิจารณ์ชั้นกรรมการท่านที่ 4 เพิ่มเติม เอากลับไปวน STEP 3 ใหม่ทันที ไม่เถียง
- ถ้า cross-exam เจอจุดอ่อนที่แก้ไม่ได้กลางทาง ให้ทิ้งไอเดียนั้นเงียบ ๆ แล้วเริ่มใหม่ ไม่ต้องขอโทษยืดยาว บอกสั้น ๆ ว่ากำลังรื้อใหม่เพราะอะไร แล้วเสนอของใหม่เลย
